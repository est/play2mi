说明

为什么要点两次？

浏览器的跨域（CORS）规则会让别的网站无法调用小米云接口。这个书签的思路是： 让界面运行在小米自己的域名上，这样调用就是“同源”，没有任何障碍。

  1. 在任意页面点书签 → 弹确认框 → 确认后打开 api2.mina.mi.com（小爱云域名）；
  2. 在那个窗口再点一次书签 → 注入控制面板（所以第一次必须点两次）。

此后不加 ?t= 的 import() 会被浏览器缓存、不再重复执行， 所以书签内置了时间戳来强制每次重新执行。

登录流程

没登录时面板会引导你：弹窗打开 account.xiaomi.com → 在弹窗内再点一次书签 → 用【米家 APP】扫描二维码（免密码、免短信）→ 登录页把凭证写进小米域 Cookie → 弹窗自动通知控制台。

首次 = 3 次书签点击 + 一次扫码；日常 = 在控制台页点一下即可， 凭证由浏览器自己保存，有效期内不用重复登录。

隐私与安全
  • 无服务器：本页只做说明书；登录与控制全部在你的浏览器与小米云之间直连完成。
  • 凭证存在哪？ 浏览器自己的 Cookie（serviceToken 由小米登录链路写入 .mina.mi.com，passToken 是 HttpOnly，脚本也读不到）。 没有第三方备份与传输。
  • 退出登录：去 account.xiaomi.com 退出即可。
常见问题
  • 控制台页显示 403 Forbidden？ 正常。api2.mina.mi.com 没有网页首页， 书签借它的“域名”做同源执行环境，服务器返回的 403 页也是合法网页，书签照常运行。
  • 点书签没反应？ 确认拖到书签栏而不是收藏夹二级目录；地址栏直接粘贴 javascript: 会被浏览器裁掉，必须通过书签点击。
  • 能播放 http:// 非加密地址吗？ 可以——浏览器只是把地址字符串传给小米云， 由音箱去拉流，与页面协议无关。
  • 关闭面板 / 标签页会停歌吗？ 不会，面板从不主动停止播放。
